## Θέμα Β: Ανάλυση κώδικα

Δίνεται κώδικας και ζητείται η έξοδος ή ο εντοπισμός σφάλματος.

```python
# Τι εμφανίζει ο παρακάτω κώδικας;
s = 0
for i in range(1, 6):
    if i % 2 == 0:
        continue
    s += i
print(s)
```

!!! tip "Μέθοδος"
    Φτιάξε **πίνακα τιμών** (trace table) με τις μεταβλητές σε κάθε επανάληψη.

| i | i%2==0 | s |
| --- | --- | --- |
| 1 | όχι | 1 |
| 2 | ναι (continue) | 1 |
| 3 | όχι | 4 |
| 4 | ναι (continue) | 4 |
| 5 | όχι | 9 |

Έξοδος: `9`

## Θέμα Γ: Υλοποίηση αλγορίθμου

Ζητείται πλήρης λύση σε πρόβλημα.

**Παράδειγμα:** Δίνεται λίστα βαθμών. Να υπολογιστεί ο Μ.Ο., το πλήθος των προβιβάσιμων και ο υψηλότερος βαθμός.

```python
def analysh_vathmologias(vathmoi):
    if not vathmoi:
        return None

    mo = sum(vathmoi) / len(vathmoi)
    provivasimoi = 0
    megistos = vathmoi[0]

    for v in vathmoi:
        if v >= 5:
            provivasimoi += 1
        if v > megistos:
            megistos = v

    return {
        "mesos_oros": round(mo, 2),
        "provivasimoi": provivasimoi,
        "megistos": megistos
    }

dedomena = [8.5, 4.0, 9.5, 6.0, 3.5, 10.0]
apotelesma = analysh_vathmologias(dedomena)
for kleidi, timi in apotelesma.items():
    print(kleidi, ":", timi)
```

## Θέμα Δ: Σύνθετο πρόβλημα

Συνδυασμός δομών δεδομένων και αλγορίθμων.

**Παράδειγμα:** Ταξινόμηση μαθητών κατά βαθμό (φθίνουσα) με διατήρηση του ονόματος.

```python
mathites = [
    {"onoma": "Μαρία", "vathmos": 9.5},
    {"onoma": "Γιώργος", "vathmos": 7.0},
    {"onoma": "Ελένη", "vathmos": 10.0},
    {"onoma": "Νίκος", "vathmos": 8.5}
]

# Ταξινόμηση με κλειδί
katalogos = sorted(mathites, key=lambda m: m["vathmos"], reverse=True)

print("ΚΑΤΑΤΑΞΗ")
print("-" * 28)
for thesi, m in enumerate(katalogos, start=1):
    print(str(thesi) + ". " + m["onoma"] + " — " + str(m["vathmos"]))
```
