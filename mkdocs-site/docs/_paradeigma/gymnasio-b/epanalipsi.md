# Δομές Επανάληψης

Οι δομές επανάληψης (βρόχοι) μας επιτρέπουν να εκτελούμε τις ίδιες εντολές πολλές φορές.

## Οι τρεις δομές

| Δομή | Πότε τη χρησιμοποιούμε |
| --- | --- |
| `ΓΙΑ ... ΑΠΟ ... ΜΕΧΡΙ` | Όταν **ξέρουμε** πόσες επαναλήψεις θέλουμε |
| `ΟΣΟ ... ΕΠΑΝΑΛΑΒΕ` | Όταν επαναλαμβάνουμε **όσο** ισχύει μια συνθήκη |
| `ΜΕΧΡΙΣ_ΟΤΟΥ` | Όταν θέλουμε **τουλάχιστον μία** εκτέλεση |

## 1. Η δομή ΓΙΑ

```glossa
ΑΛΓΟΡΙΘΜΟΣ Άθροισμα_1_έως_10
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: i, s
ΑΡΧΗ
  s <- 0
  ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ 10
    s <- s + i
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  ΓΡΑΨΕ 'Άθροισμα: ', s
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

Σε Python:

```python
s = 0
for i in range(1, 11):
    s = s + i
print("Άθροισμα:", s)
```

!!! note "Προσοχή στο range"
    Το `range(1, 11)` δίνει τους αριθμούς **1 έως 10** — το τελευταίο όριο δεν συμπεριλαμβάνεται!

## 2. Η δομή ΟΣΟ

```glossa
ΑΛΓΟΡΙΘΜΟΣ Αντίστροφη_Μέτρηση
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: n
ΑΡΧΗ
  n <- 5
  ΟΣΟ n > 0 ΕΠΑΝΑΛΑΒΕ
    ΓΡΑΨΕ n
    n <- n - 1
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  ΓΡΑΨΕ 'Τέλος!'
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

```python
n = 5
while n > 0:
    print(n)
    n = n - 1
print("Τέλος!")
```

## 3. Μετρητές και Αθροιστές

```python
# Μέτρηση άρτιων αριθμών σε 10 εισόδους
metritis = 0
athroisma = 0

for i in range(10):
    x = int(input("Δώσε αριθμό: "))
    if x % 2 == 0:
        metritis = metritis + 1
        athroisma = athroisma + x

print("Πλήθος άρτιων:", metritis)
print("Άθροισμα άρτιων:", athroisma)
```

## 4. Φωλιασμένοι βρόχοι — Πίνακας πολλαπλασιασμού

```python
for i in range(1, 6):
    grammi = ""
    for j in range(1, 6):
        grammi = grammi + str(i * j) + "\t"
    print(grammi)
```

## ⚠️ Άπειρος βρόχος

Αν η συνθήκη δεν γίνει ποτέ ψευδής, ο βρόχος δεν τελειώνει:

```python
# ΠΡΟΣΟΧΗ: αυτός ο κώδικας δεν τελειώνει ποτέ!
# n = 5
# while n > 0:
#     print(n)      # ξεχάσαμε το n = n - 1
```

!!! danger "Κανόνας"
    Μέσα σε κάθε `while` πρέπει κάτι να αλλάζει ώστε η συνθήκη να γίνει τελικά ψευδής.

## Ασκήσεις

1. Υπολόγισε το γινόμενο `1 × 2 × ... × 5` (παραγοντικό).
2. Εμφάνισε τους αριθμούς από το 10 έως το 1 με αντίστροφη σειρά.
3. Διάβασε αριθμούς μέχρι ο χρήστης να δώσει `0` και εμφάνισε το άθροισμά τους.
