## ➕ Πώς προσθέτω νέο μάθημα

### Τρόπος 1: Μέσω του Pandoc Studio (προτείνεται)

1. Άνοιξε το [Visual Pandoc Studio](/pandoc/).
2. Γράψε το μάθημα σε Markdown με ζωντανή προεπισκόπηση.
3. Διάλεξε τάξη και τίτλο στην καρτέλα **«Αποστολή στο MkDocs»**.
4. Πάτησε **Αποστολή** — το μάθημα δημοσιεύεται αυτόματα.

### Τρόπος 2: Χειροκίνητα

```bash
# 1. Δημιούργησε το αρχείο
nano /opt/school-portal/mkdocs-site/docs/gymnasio-a/neo-mathima.md

# 2. Πρόσθεσέ το στο nav του mkdocs.yml
nano /opt/school-portal/mkdocs-site/mkdocs.yml

# 3. Ανακατασκευή (ή περίμενε το αυτόματο rebuild)
sudo systemctl start school-mkdocs.service
```
