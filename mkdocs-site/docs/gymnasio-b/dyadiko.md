# Το Δυαδικό Σύστημα

Ο υπολογιστής «καταλαβαίνει» μόνο δύο καταστάσεις: **0** και **1**. Κάθε τέτοιο ψηφίο ονομάζεται **bit** (binary digit).

## Βασικές μονάδες

| Μονάδα | Ισοδυναμία |
| --- | --- |
| 1 bit | 0 ή 1 |
| 1 Byte | 8 bits |
| 1 KB | 1024 Bytes |
| 1 MB | 1024 KB |

## Δυνάμεις του 2

| 2⁷ | 2⁶ | 2⁵ | 2⁴ | 2³ | 2² | 2¹ | 2⁰ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |

## Δυαδικό → Δεκαδικό

Πολλαπλασιάζουμε κάθε ψηφίο με την αντίστοιχη δύναμη του 2 και αθροίζουμε.

**Παράδειγμα:** `1011₂`

| Ψηφίο | 1 | 0 | 1 | 1 |
| --- | --- | --- | --- | --- |
| Βάρος | 8 | 4 | 2 | 1 |
| Γινόμενο | 8 | 0 | 2 | 1 |

Άρα `1011₂ = 8 + 0 + 2 + 1 = 11₁₀`

```python
def dyadiko_se_dekadiko(bits):
    """Μετατρέπει δυαδική συμβολοσειρά σε δεκαδικό αριθμό."""
    result = 0
    for psifio in bits:
        result = result * 2 + int(psifio)
    return result

print("1011 =", dyadiko_se_dekadiko("1011"))
print("11010 =", dyadiko_se_dekadiko("11010"))

# Ενσωματωμένος τρόπος της Python
print("Με int():", int("1011", 2))
```

## Δεκαδικό → Δυαδικό

Διαιρούμε συνεχώς με το 2 και κρατάμε τα υπόλοιπα **από κάτω προς τα πάνω**.

**Παράδειγμα:** `13₁₀`

| Διαίρεση | Πηλίκο | Υπόλοιπο |
| --- | --- | --- |
| 13 ÷ 2 | 6 | **1** |
| 6 ÷ 2 | 3 | **0** |
| 3 ÷ 2 | 1 | **1** |
| 1 ÷ 2 | 0 | **1** |

Διαβάζοντας από κάτω προς τα πάνω: `1101₂`

```python
def dekadiko_se_dyadiko(n):
    """Μετατρέπει δεκαδικό αριθμό σε δυαδική συμβολοσειρά."""
    if n == 0:
        return "0"
    ypoloipa = []
    while n > 0:
        ypoloipa.append(str(n % 2))
        n = n // 2
    return "".join(reversed(ypoloipa))

for num in [0, 5, 13, 42, 255]:
    print(num, "->", dekadiko_se_dyadiko(num))

# Ενσωματωμένος τρόπος (το 0b είναι το πρόθεμα δυαδικού)
print("Με bin():", bin(13))
```
