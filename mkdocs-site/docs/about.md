# Σχετικά με την Ψηφιακή Πύλη

Η **Ψηφιακή Πύλη Σχολείου & Εργαστηρίου** είναι μια ολοκληρωμένη πλατφόρμα εκπαιδευτικού υλικού Πληροφορικής για Γυμνάσιο και Λύκειο.

## 🧩 Υπηρεσίες

| Διαδρομή | Υπηρεσία | Πρόσβαση |
| --- | --- | --- |
| `/` | Κεντρικό Dashboard | Ελεύθερη |
| `/docs/` | Εκπαιδευτικό Υλικό | Ελεύθερη |
| `/lab/` | Πρόγραμμα Εργαστηρίου | Προβολή ελεύθερη |
| `/pandoc/` | Visual Pandoc Studio | 🔐 Καθηγητές |
| `/docs/teachers/` | Λύσεις Καθηγητή | 🔐 Καθηγητές |

## ⚙️ Τεχνολογίες

- **Nginx** — διακομιστής ιστού (θύρα 80)
- **Material for MkDocs** — τεκμηρίωση εκπαιδευτικού υλικού
- **FastAPI + Uvicorn** — Visual Pandoc Studio
- **Pandoc + WeasyPrint** — μετατροπές εγγράφων και PDF με ελληνικά
- **Pyodide (WebAssembly)** — εκτέλεση Python στον browser
- **Tailwind CSS + Alpine.js** — διεπαφή dashboard
- **systemd** — διαχείριση υπηρεσιών

!!! success "Λειτουργεί χωρίς Internet"
    Όλα τα αρχεία (βιβλιοθήκες JavaScript, Pyodide, γραμματοσειρές) φιλοξενούνται **τοπικά** στο σχολείο.
    Η πύλη λειτουργεί κανονικά ακόμη και χωρίς σύνδεση στο Internet.

## 🐍 Πώς εκτελώ Python;

1. Άνοιξε οποιοδήποτε μάθημα με μπλοκ Python.
2. Πάτησε το κουμπί **▶ Εκτέλεση**.
3. Την πρώτη φορά φορτώνεται η Python στον browser (~15 MB, μία φορά ανά συνεδρία).
4. Δες το αποτέλεσμα αμέσως κάτω από τον κώδικα.

!!! note "Ιδιωτικότητα"
    Ο κώδικάς σου **δεν αποστέλλεται** στον διακομιστή. Εκτελείται αποκλειστικά στον υπολογιστή σου.

## 🔐 Πρόσβαση Καθηγητών

Οι περιοχές καθηγητών προστατεύονται σε δύο επίπεδα:

1. **Dashboard:** κωδικός ξεκλειδώματος για εμφάνιση των καρτών.
2. **Διακομιστής (HTTP Basic Auth):** πραγματικός έλεγχος πρόσβασης στα `/pandoc/` και `/docs/teachers/`.
   - Όνομα χρήστη: `teacher`
   - Κωδικός: ο κωδικός της Ζώνης Καθηγητών

## 🛠️ Για τους διαχειριστές

```bash
# Ενημέρωση εκπαιδευτικού υλικού
sudo systemctl start school-mkdocs.service

# Κατάσταση υπηρεσιών
systemctl status school-pandoc.service nginx

# Αρχεία καταγραφής
journalctl -u school-pandoc.service -f

# Πλήρης επανεγκατάσταση / ενημέρωση
sudo /opt/school-portal/install.sh
```
