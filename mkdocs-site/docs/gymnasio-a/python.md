# Python — Τα πρώτα μου προγράμματα

Η **Python** είναι μια γλώσσα προγραμματισμού εύκολη στην ανάγνωση. Σε αυτή την πύλη μπορείς να εκτελείς Python **απευθείας στον browser** — πάτησε το κουμπί **▶ Εκτέλεση**!

## 1. Γεια σου κόσμε!

```python
print("Γεια σου κόσμε!")
print("Καλώς ήρθα στην Python 🐍")
```

## 2. Μεταβλητές

Οι μεταβλητές είναι «κουτιά» που κρατούν τιμές.

```python
onoma = "Μαρία"
ilikia = 13
ypsos = 1.62

print("Όνομα:", onoma)
print("Ηλικία:", ilikia)
print("Ύψος:", ypsos, "μέτρα")
```

## 3. Πράξεις

```python
a = 12
b = 5

print("Άθροισμα:", a + b)
print("Διαφορά:", a - b)
print("Γινόμενο:", a * b)
print("Πηλίκο:", a / b)
print("Ακέραιο πηλίκο:", a // b)
print("Υπόλοιπο:", a % b)
print("Δύναμη:", a ** 2)
```

## 4. Είσοδος από τον χρήστη

```python
onoma = input("Πώς σε λένε; ")
print("Γεια σου,", onoma + "!")
```

!!! warning "Προσοχή στους τύπους"
    Η `input()` επιστρέφει **πάντα κείμενο**. Για αριθμούς χρειάζεται μετατροπή με `int()` ή `float()`.

```python
x = int(input("Δώσε έναν ακέραιο: "))
y = int(input("Δώσε άλλον έναν: "))
print("Το άθροισμά τους είναι", x + y)
```

## 5. Δομή επιλογής

```python
vathmos = float(input("Δώσε τον βαθμό σου: "))

if vathmos >= 9.5:
    print("Άριστα! 🏆")
elif vathmos >= 5:
    print("Προβιβάσιμος 👍")
else:
    print("Χρειάζεται προσπάθεια 📖")
```

## 6. Επανάληψη

```python
for i in range(1, 6):
    print("Γραμμή", i)

print("---")

metritis = 3
while metritis > 0:
    print("Αντίστροφη μέτρηση:", metritis)
    metritis = metritis - 1
print("Εκκίνηση! 🚀")
```

## 🎯 Μικρό project: Υπολογισμός Μ.Ο.

```python
v1 = float(input("Βαθμός 1ου μαθήματος: "))
v2 = float(input("Βαθμός 2ου μαθήματος: "))
v3 = float(input("Βαθμός 3ου μαθήματος: "))

mo = (v1 + v2 + v3) / 3
print("Μέσος όρος:", round(mo, 2))

if mo >= 9.5:
    print("Χαρακτηρισμός: Άριστα")
elif mo >= 5:
    print("Χαρακτηρισμός: Καλώς")
else:
    print("Χαρακτηρισμός: Χρειάζεται βελτίωση")
```
