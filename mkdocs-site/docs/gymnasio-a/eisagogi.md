# Εισαγωγή στην Πληροφορική

## Τι είναι η Πληροφορική;

Η **Πληροφορική** είναι η επιστήμη που μελετά την αυτόματη επεξεργασία της πληροφορίας με τη βοήθεια υπολογιστών.

!!! note "Βασικές έννοιες"
    - **Δεδομένα (data):** ακατέργαστα στοιχεία, π.χ. ο αριθμός `18`.
    - **Πληροφορία (information):** δεδομένα με νόημα, π.χ. «ο μαθητής είναι 18 ετών».
    - **Επεξεργασία:** η μετατροπή δεδομένων σε πληροφορία.

## Υλικό και Λογισμικό

| Κατηγορία | Περιγραφή | Παραδείγματα |
| --- | --- | --- |
| **Υλικό (Hardware)** | Ό,τι μπορούμε να αγγίξουμε | Οθόνη, πληκτρολόγιο, CPU, RAM |
| **Λογισμικό (Software)** | Τα προγράμματα | Λειτουργικό σύστημα, περιηγητής ιστού, παιχνίδια |

### Μονάδες μέτρησης μνήμης

| Μονάδα | Ισοδυναμία |
| --- | --- |
| 1 Byte | 8 bit |
| 1 KB | 1024 Bytes |
| 1 MB | 1024 KB |
| 1 GB | 1024 MB |
| 1 TB | 1024 GB |


## Ένα πρώτο παράδειγμα

Ο υπολογιστής παίρνει δύο αριθμούς και υπολογίζει το άθροισμά τους:

```python
# Δεδομένα εισόδου
a = 7
b = 5

# Επεξεργασία
athroisma = a + b

# Έξοδος πληροφορίας
print("Το άθροισμα είναι:", athroisma)
```

!!! question "Σκέψου"
    Αν αλλάξεις τις τιμές των `a` και `b`, τι θα εμφανιστεί; Δοκίμασέ το πατώντας **▶ Εκτέλεση**!
