# Ψευδογλώσσα (ΓΛΩΣΣΑ)

Η **ψευδογλώσσα** είναι ένας τρόπος περιγραφής αλγορίθμων που μοιάζει με γλώσσα προγραμματισμού, αλλά είναι πιο κοντά στα Ελληνικά. Δεν εκτελείται από τον υπολογιστή — μας βοηθά να **σχεδιάσουμε** τη λύση.

## Δομή ενός αλγορίθμου

```glossa
ΑΛΓΟΡΙΘΜΟΣ Άθροισμα
! Υπολογίζει το άθροισμα δύο αριθμών
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: α, β, γ
ΑΡΧΗ
  ΔΙΑΒΑΣΕ α, β
  γ <- α + β
  ΓΡΑΨΕ 'Το άθροισμα είναι: ', γ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

!!! info "Χρωματισμός κώδικα"
    Τα μπλοκ `glossa` χρωματίζονται αυτόματα: οι **λέξεις-κλειδιά**, τα *strings*, οι αριθμοί και τα σχόλια ξεχωρίζουν για ευκολότερη ανάγνωση.

## Τύποι δεδομένων

| Τύπος | Περιγραφή | Παράδειγμα |
| --- | --- | --- |
| `ΑΚΕΡΑΙΕΣ` | Ακέραιοι αριθμοί | `-5`, `0`, `42` |
| `ΠΡΑΓΜΑΤΙΚΕΣ` | Δεκαδικοί αριθμοί | `3.14`, `-0.5` |
| `ΧΑΡΑΚΤΗΡΕΣ` | Κείμενο | `'Καλημέρα'` |
| `ΛΟΓΙΚΕΣ` | Τιμές αλήθειας | `ΑΛΗΘΗΣ`, `ΨΕΥΔΗΣ` |

## Δομή επιλογής

```glossa
ΑΛΓΟΡΙΘΜΟΣ Έλεγχος_Βαθμού
ΜΕΤΑΒΛΗΤΕΣ
  ΠΡΑΓΜΑΤΙΚΕΣ: βαθμος
ΑΡΧΗ
  ΔΙΑΒΑΣΕ βαθμος
  ΑΝ βαθμος >= 9.5 ΤΟΤΕ
    ΓΡΑΨΕ 'Άριστα'
  ΑΛΛΙΩΣ_ΑΝ βαθμος >= 5 ΤΟΤΕ
    ΓΡΑΨΕ 'Προβιβάσιμος'
  ΑΛΛΙΩΣ
    ΓΡΑΨΕ 'Μη προβιβάσιμος'
  ΤΕΛΟΣ_ΑΝ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

## Δομή επανάληψης

```glossa
ΑΛΓΟΡΙΘΜΟΣ Μέτρηση
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: i
ΑΡΧΗ
  ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ 5
    ΓΡΑΨΕ 'Γεια σου κόσμε!'
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

## Αντιστοιχία ψευδογλώσσας ↔ Python

| Ψευδογλώσσα | Python |
| --- | --- |
| `ΔΙΑΒΑΣΕ x` | `x = int(input())` |
| `ΓΡΑΨΕ x` | `print(x)` |
| `x <- 5` | `x = 5` |
| `ΑΝ ... ΤΟΤΕ` | `if ...:` |
| `ΑΛΛΙΩΣ` | `else:` |
| `ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ 5` | `for i in range(1, 6):` |
| `ΟΣΟ ... ΕΠΑΝΑΛΑΒΕ` | `while ...:` |

## Το ίδιο σε Python

```python
# Ο αλγόριθμος "Άθροισμα" σε Python
a = int(input("Δώσε τον πρώτο αριθμό: "))
b = int(input("Δώσε τον δεύτερο αριθμό: "))
g = a + b
print("Το άθροισμα είναι:", g)
```

!!! tip "Δοκίμασέ το"
    Πάτησε **▶ Εκτέλεση** και δώσε τιμές στα παράθυρα που θα εμφανιστούν.
