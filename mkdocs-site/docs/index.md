!!! info "Πώς λειτουργεί η εκτέλεση Python;"
    Η Python τρέχει **μέσα στον browser σου** μέσω Pyodide (WebAssembly). Δεν χρειάζεται εγκατάσταση,
    δεν αποστέλλεται κώδικας στον διακομιστή και λειτουργεί ακόμη και χωρίς σύνδεση στο Internet,
    καθώς όλα τα αρχεία φιλοξενούνται τοπικά στο σχολείο.
