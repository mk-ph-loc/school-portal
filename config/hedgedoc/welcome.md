# 🏫 Καλώς ήρθατε στο Συνεργατικό Markdown!

Αυτό είναι το **συνεργατικό περιβάλλον συγγραφής Markdown** της Ψηφιακής Πύλης του σχολείου μας.
Όλοι όσοι ανοίγουν τον ίδιο σύνδεσμο βλέπουν και επεξεργάζονται το κείμενο **ταυτόχρονα, ζωντανά** — χωρίς λογαριασμό! :tada:

:::info
**Πώς ξεκινώ;** Πατήστε **«Νέα σημείωση»** στην αρχική σελίδα [/md-pad/](/md-pad/) ή ανοίξτε κατευθείαν έναν δικό σας σύνδεσμο, π.χ. `/md-pad/gymnasio-a-omada1` — η σημείωση δημιουργείται αυτόματα (FreeURL).
Μοιραστείτε τον σύνδεσμο με την ομάδα σας και γράψτε όλοι μαζί!
:::

:::success
**Έτοιμο πρότυπο:** Το πλήρες ελληνικό πρότυπο επίδειξης **όλων** των δυνατοτήτων βρίσκεται στη σημείωση [**📋 Πρότυπο Δυνατοτήτων (template-demo)**](/md-pad/template-demo). Αντιγράψτε το περιεχόμενό του σε νέα σημείωση για να ξεκινήσετε με έτοιμες δομές!
:::

## 🧭 Τι μπορώ να κάνω εδώ;

- [x] Να γράψω σημειώσεις μαθήματος με **έντονα**, *πλάγια*, ~~διαγραμμένα~~, ==υπογραμμισμένα== και `inline κώδικα`
- [x] Να φτιάξω λίστες ελέγχου εργασιών ομάδας (όπως αυτή!)
- [x] Να σχεδιάσω διαγράμματα ροής & ακολουθίας με Mermaid
- [x] Να γράψω μαθηματικές εξισώσεις LaTeX: $E = mc^2$
- [ ] Να ανεβάσω εικόνα με drag-n-drop ή επικόλληση (αποθηκεύεται τοπικά στον server)
- [ ] Να δημοσιεύσω τη σημείωση στα μαθήματα MkDocs μέσω του [/md-publish/](/md-publish/) (καθηγητής)

:::

## ⌨️ Βασικές συντομεύσεις

| Συντόμευση | Λειτουργία |
| ---------- | ---------- |
| ++ctrl+b++ | Έντονα |
| ++ctrl+i++ | Πλάγια |
| ++ctrl+k++ | Διαγραμμένα |
| ++ctrl+z++ / ++ctrl+y++ | Αναίρεση / Επανάληψη |
| ++ctrl+s++ | Άμεση αποθήκευση (αποθηκεύεται και αυτόματα) |

> 💡 Οι τρεις λειτουργίες προβολής (κουμπιά πάνω δεξιά): **Edit** (μόνο επεξεργασία), **Both** (χωρισμένη οθόνη), **View** (μόνο αποτέλεσμα). Δοκιμάστε και τη 🌙 νυχτερινή λειτουργία!
