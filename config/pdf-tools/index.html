Συγχώνευση πολλών PDF σε ένα

Πρόσθεσε 2 ή περισσότερα αρχεία PDF, όρισε τη σειρά με τα βελάκια και πάτα «Συγχώνευση».

    Εξαγωγή συγκεκριμένων σελίδων (Split)

    Διάλεξε ένα PDF και γράψε τις σελίδες που θέλεις να κρατήσεις, π.χ. 1-3, 5, 8-10.

    Προσθήκη υδατογραφήματος & αρίθμησης σελίδων

    Πρόσθεσε διαγώνιο υδατογράφημα (π.χ. «ΠΡΟΧΕΙΡΟ», «ΕΜΠΙΣΤΕΥΤΙΚΟ») ή/και αρίθμηση στο κάτω μέρος κάθε σελίδας.

    ℹ️ Η επεξεργασία γίνεται αποκλειστικά στη μνήμη του browser σου με JavaScript/WebAssembly (pdf-lib). Κανένα αρχείο δεν αποστέλλεται στο σχολικό δίκτυο ή στο διαδίκτυο. Για υδατογράφημα με ελληνικούς χαρακτήρες χρησιμοποιείται ενσωματωμένη γραμματοσειρά Unicode — το αποτέλεσμα κατεβαίνει απευθείας στον υπολογιστή σου.
