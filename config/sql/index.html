📖 Σύντομη βοήθεια SQL
  • SELECT στήλες FROM πίνακας — επιλογή δεδομένων (* = όλες οι στήλες).
  • WHERE συνθήκη — φιλτράρισμα γραμμών, π.χ. ΤΑΞΗ = 'Α'.
  • JOIN ... ON ... — συνδυασμός πινάκων με κοινό κλειδί.
  • GROUP BY + AVG/COUNT/SUM/MAX/MIN — ομαδοποίηση & στατιστικά.
  • ORDER BY στήλη DESC — ταξινόμηση (φθίνουσα).
  • Επιτρέπονται και INSERT / UPDATE / DELETE / CREATE TABLE — αν χαλάσεις τη βάση, πάτα «Επαναφορά Αρχικής Βάσης».
  • Πολλά ερωτήματα μαζί χωρίζονται με ; και εκτελούνται διαδοχικά.
